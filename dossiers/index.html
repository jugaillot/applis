Accès au dépôt GitHub des dossiers

Les dossiers sont rangés dans un dépôt GitHub privé : chaque modification est gardée (historique), et Claude peut aussi les créer ou les modifier depuis vos conversations. Cette clé n’est à saisir qu’une fois : elle est ensuite partagée avec tes autres appareils par la synchronisation de l’atelier.
  1. Sur GitHub, crée un dépôt privé nommé dossiers (sans rien cocher d’autre).
  2. Ouvre Nouveau jeton (fine-grained) : nom « La Suite dossiers », expiration la plus longue possible.
  3. « Repository access » → Only select repositories → choisis dossiers et applis (applis sert aux liens publics).
  4. « Permissions » → « Repository permissions » → Contents : Read and write.
  5. Génère le jeton, copie-le et colle-le ci-dessous.

Charte graphique

Elle s’applique à tous les documents : aperçu, PDF, Word et pages publiques.

Lien public

Une page en lecture seule, avec ta charte, accessible sans mot de passe par toute personne qui a le lien. Elle se met à jour toute seule quand tu modifies le document. Compte une minute avant qu’elle soit en ligne.
