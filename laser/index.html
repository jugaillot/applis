Essai de connexion USB

Branche la machine à l’ordinateur en USB, allume-la, puis utilise Chrome ou Edge. Le test fait seulement bouger la tête, sans laser.

Sur la machine

  1. Copie le fichier .rd sur une clé USB (FAT32), à la racine.
  2. Branche la clé sur le port USB de la machine.
  3. Sur le panneau : Menu → Fichier USB (U-disk), choisis le fichier.
  4. Place la tête au coin voulu, touche Origine, puis Cadre pour contrôler, puis Start.
Premier essai : un petit carré, puissance basse, lunettes de protection. Les réglages sont des points de départ à tester sur ta matière.
